# 助手生命周期闭环验证

验证日期：2026-09-07。范围：本地 Electron 桌面端、真实 Pi 执行器；测试使用 `/tmp/wework-desktop-qa` 隔离团队，未操作用户正式助手。

产品约定：每位助手只有一个当前持续会话。关闭工作台、重启应用继续原会话；重新开始会清空当前上下文并保存只读历史。没有新建、重命名或切换多个会话的入口。

## 实际桌面操作

- 取消入职不创建助手；空姓名不能提交。
- 选择 Pi 与模型后入职，助手拥有有效执行配置及空白上下文。
- 新助手首次消息收到真实回复。
- 关闭、重新打开工作台保留同一会话；退出并重启应用仍可继续回复。
- 清空上下文后查看旧消息，只读历史不改变当前会话；继续发送获得新回复。
- 移除确认可取消，取消后助手仍存在。
- 助手正在执行工具时确认移除，运行状态先到 cancelled，再移除助手；刷新后不会恢复。
- 此前同环境已验证运行中补充指令（steering）在同一 Pi run 生效。

## 回归覆盖及修复

- 发送、重新开始和删除按助手串行处理，防止快速操作串上下文。
- 重新开始无法确认停止旧执行时，保留原会话。
- 未完成工作退回待分配，完成工作及交付文档保留在团队记录中。
- 移除助手解除项目负责人和流程节点指派，取消尚未执行的群聊投递。
- 绑定有效 Pi SessionExecution 的助手可以被分配工作，不再误报缺少旧版 runtime profile。

## 边界

负责人需要先转交负责人身份再移除。工作目录和底层执行器历史文件保留；移除不是磁盘文件擦除。本次真实模型交互验证针对 Pi，未将其他执行器或远程服务端算作已实测通过。

最终检查：前端 157 项、Runtime 207 项、桌面 7 项通过；`npm run package` 成功。Runtime 回归曾发现群聊结束瞬间将旧 checkpoint 误读为中断的竞态，已增加终态复核及确定性测试后通过。
