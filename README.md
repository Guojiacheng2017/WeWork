# WeWork

**让 AI 助手围绕同一个目标协作。**

**Bring AI assistants together around a shared goal.**

[中文](#中文) · [English](#english)

## 中文

WeWork 是一个以本地工作空间为中心的 AI 团队协作桌面应用。把目标交给团队，在同一个界面中组织助手、交流需求、安排任务，并跟进执行过程与交付结果。

### 一个工作空间，连接团队与任务

- **组织助手团队**：创建团队，为助手配置角色与工作职责，让不同任务有明确的负责人。
- **围绕任务交流**：在团队群聊中沟通，通过 @ 提及助手，或进入单个助手的工作台继续讨论。
- **跟进执行过程**：查看助手状态、会话、工具活动与任务进度，在需要时补充说明或停止运行。
- **管理项目工作**：按需启用项目管理，用任务列表、看板和甘特图组织事项、状态与时间安排。
- **编排协作流程**：通过工作流视图组织任务依赖，查看执行状态与交接进展。
- **掌握本地数据**：围绕本地工作空间保存团队与项目内容，支持工作空间导入和导出。

### 从目标到交付

1. 创建团队，添加助手并明确各自职责。
2. 选择工作空间，配置可用的执行环境。
3. 在群聊中提出目标，或为助手安排具体任务。
4. 在工作台、项目视图和工作流中跟进进度，查看结果并继续迭代。

### 使用前准备

当前助手执行使用 Pi，需要先在本机安装并完成认证。桌面应用提供本地工作空间选择与任务执行能力。

## English

WeWork is a desktop app for AI team collaboration built around a local workspace. Give your team a goal, organize assistants, discuss requirements, assign tasks, and follow execution and deliverables in one place.

### One workspace for your team and its tasks

- **Organize assistant teams**: Create teams and define each assistant’s role and responsibilities so tasks have clear owners.
- **Discuss work in context**: Use team chat, @mention assistants, or continue a conversation in an individual assistant’s workbench.
- **Follow execution**: Inspect assistant status, sessions, tool activity, and task progress. Add guidance or stop a run when needed.
- **Manage project work**: Enable project management when needed and organize work, status, and schedules with issue lists, boards, and Gantt charts.
- **Coordinate workflows**: Organize task dependencies in the workflow view and follow execution and handoffs.
- **Keep control of local data**: Store team and project content around a local workspace, with workspace import and export support.

### From goal to delivery

1. Create a team, add assistants, and define their responsibilities.
2. Choose a workspace and configure an available execution environment.
3. Describe a goal in team chat or assign specific tasks to assistants.
4. Follow progress in the workbench, project views, and workflows, then review results and iterate.

### Before you start

Assistant execution currently uses Pi, which must be installed and authenticated on your device. The desktop app provides local workspace selection and task execution.
